# Live-транскрипция системного звука

Слушаешь доклад или созвон — текст копится в файле, который читается по ходу.
Обоснование решений и замеры: [`docs/live-transcribe.md`](../../../../docs/live-transcribe.md).

## Запуск

Два процесса: один пишет звук чанками, второй их распознаёт.

```bash
# терминал 1 — захват
./capture.sh ~/podlodka/chunks 30

# терминал 2 — распознавание
./transcribe_chunks.py ~/podlodka/chunks ~/podlodka/live.md \
    --chunk-seconds 30 --title "Podlodka: доклад про AI"
```

Читать по ходу, в том числе с VDS:

```bash
tail -f ~/podlodka/live.md
ssh mac-home 'tail -c 3000 ~/podlodka/live.md'
```

## Где распознавать

По умолчанию локально, `mlx-whisper large-v3`. Можно отдать на видеокарту:

```bash
VOICE_WHISPER_URL=http://192.168.88.13:8000 ./transcribe_chunks.py ...
```

Замеры на 2026-09-02 — оба варианта с большим запасом:

| | чанк 30 с | чанк 60 с |
|---|---|---|
| mac-home, M1 Max, mlx | 1.6 с (18×) | 6.6 с (9×) |
| ubuntu-home, CUDA, turbo | 0.54 с (55×) | 1.3 с (46×) |

CUDA быстрее, но `ubuntu-home` — dual-boot и может подняться в Windows, где
whisper не стоит. Для конференции основной путь локальный.

## Словарь техтерминов

```bash
VOICE_INITIAL_PROMPT="Обсуждаем SwiftUI, Core Data, LLM, embeddings, RAG" ./transcribe_chunks.py ...
```

Влияет сильнее выбора модели, но эффект модель-зависимый: на large-v3
выправил 15 клипов из 24, на turbo дал 2 улучшения и 2 регресса. Подбирать
надо на реальном звуке, не вслепую — [замеры](../../../../bench/whisper-accuracy/comparison-2026-08-01.md).

## Режимы

Конференция — просто запускаешь, это личное обучение.

Созвон или собеседование, где в записи чужие голоса:

```bash
./transcribe_chunks.py ... --require-consent --consent --title "Собеседование"
```

Без `--consent` процесс откажется стартовать и файл не создаст. В шапку
пишется отметка о предупреждении участников. Проверяется тестом.

## Что известно про ограничения

**Фразы делятся на стыке чанков.** ffmpeg режет встык, перехлёста нет:
«Мы запускаем.» в одном чанке, «разработку приложения» в следующем. При
чтении подряд смысл восстанавливается, поэтому усложнять не стали.

**Последний чанк не распознаётся, пока пишется следующий** — иначе получим
обрывок. То есть текст отстаёт ровно на одну длину чанка.

**Захват нужен как устройство ввода.** Системный звук сам по себе ffmpeg не
виден: на mac-home это BlackHole, на mac-work — OBS (драйвер на корпоративную
машину не ставим).

## Тесты

python3 test_transcribe_chunks.py

посторонние файлы в каталоге, отказ без подтверждения.
