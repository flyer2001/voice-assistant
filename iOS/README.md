# iOS app — Voice Assistant

iPhone-app target для voice-assistant v0.1. Использует `VoiceAssistant` Swift Package из корня repo как local dep + WhisperKit для on-device STT.

## Структура

```
iOS/
├── project.yml                    # XcodeGen spec (source of truth)
├── VoiceAssistant/
│   ├── VoiceAssistantApp.swift    # @main entry
│   ├── ContentView.swift          # SwiftUI UI
│   ├── BenchRunner.swift          # STT bench runner (skeleton)
│   ├── Info.plist                 # bundle config + permissions
│   └── Resources/                 # audio files для бенчмарка (добавятся позже)
├── VoiceAssistantTests/           # XCTest harness (добавится позже)
└── VoiceAssistant.xcodeproj/      # generated by xcodegen (не committed)
```

`VoiceAssistant.xcodeproj/` — в `.gitignore`. Регенерируется через `xcodegen generate`.

## Зависимости

- **VoiceAssistant** (local SPM, путь `../`) — backend adapter, dispatcher protocol, types
- **WhisperKit** (`argmaxinc/WhisperKit`, `0.9.0+`) — on-device Whisper STT через CoreML + Neural Engine

iOS deployment target: **17.0**. SpeechTranscriber/DictationTranscriber (iOS 26+) использует `#available` runtime check.

## Build на mac-home

### Предусловия

- Xcode 26.0+ (с `DEVELOPER_DIR` или `xcode-select -s /Applications/Xcode.app/Contents/Developer`)
- `brew install xcodegen` (через VDS proxy если ISP блокирует — см. [[reference_claude_ufo_alias]])

### Команды

```bash
cd iOS
xcodegen generate           # regenerate VoiceAssistant.xcodeproj из project.yml
open VoiceAssistant.xcodeproj   # GUI workflow

# или CLI build на симулятор
xcodebuild \
  -project VoiceAssistant.xcodeproj \
  -scheme VoiceAssistant \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  -configuration Debug \
  build
```

### Real device (iPhone 13 mini)

1. **Developer Mode на iPhone:** Settings → Privacy & Security → Developer Mode → Toggle → Restart (iOS 16+)
2. **Apple ID в Xcode:** Xcode → Settings → Accounts → добавить Apple ID (free tier OK для personal device)
3. **Подключить iPhone** через USB (или Wi-Fi paired)
4. **Signing & Capabilities tab** (в Xcode target settings): выбрать Team → Personal Team
5. **Build target → iPhone 13 mini** → ⌘R или ⌘B
6. **Trust developer на iPhone** после первого install: Settings → General → VPN & Device Management → trust your Apple ID

Personal team apps работают **7 дней**, потом нужно re-install. Этого достаточно для бенчмарка.
