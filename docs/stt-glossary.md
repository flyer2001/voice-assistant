# Глоссарий STT — что подсказывать whisper, а что вырезать после

Источник правды для двух вещей:

- **промпт** (`bench/work/prompt.txt`) — собирается из этого файла
  скриптом `bench/work/make-prompt.sh`. Руками `prompt.txt` не править:
  перезапишется.
- **фильтр** (`backend/voice-service/deploy/whisper-server/server.py`,
  `_CREDITS`) — устойчивый мусор, который режется на выходе.

Правило разделения: в **промпт** идёт то, что модель может угадать, если ей
намекнуть (термины, имена, аббревиатуры). В **фильтр** — то, что она выдумывает
на тишине и что подсказками не лечится (титры субтитров, зацикливания).

⚠️ Промпт длиной больше ~1200 символов начинает сам течь в расшифровку
(2026-10-23: на тихом куске модель выдала список имён прямо из промпта).
`make-prompt.sh` ругается, если превышено. Добавляешь термин — подумай, не
убрать ли устаревший.

## Фильтр: устойчивый мусор

Не лечится промптом — режется в `clean_segment()`. Эти строки модель выдаёт
на тишине, они взяты из субтитров в обучающем корпусе.

| Мусор | Где поймали |
|---|---|
| `Субтитры делал DimaTorzok`, `Субтитры сделал …` | дейлик 2026-10-23, 00:06:30 |
| `Редактор субтитров А.Семкин Корректор А.Егорова` | дейлик 2026-10-23, 00:01:30 |
| `Продолжение следует...` | проба записи 22.10 |
| `Спасибо за просмотр`, `Подписывайтесь` | классика корпуса, на упреждение |
| повтор одного слова («Важно. Важно. Важно… За год.») | дейлик 2026-10-23, 00:07:30 |
| перечисление имён прямо из промпта | появилось после первой правки, 2026-10-23 |

## Наблюдения без вердикта

Слышно криво, но правильный вариант пока не ясен — в промпт не тащим, чтобы
не «примагнитить» распознавание к догадке.

| Как распознало | Контекст |
|---|---|
| `на калетке Антона` | проверял оптовые поля в шторке |
| `ИНОВ-1, ИНОВ-2` | тестирование чекаута |
| `окрунут` (про PR) | «надеюсь, его быстрее …» |
| `в С3` | «она потом в С3?» про скоуп |
| `батьё переписывается от лица разработчиков` | про ботов в ревью |

Накопится контекст — переносить наверх, в домен.
