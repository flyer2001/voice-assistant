  файлов, включая индекс с 36 ссылками; все его относительные файловые цели

  **не проверены**. Отдельно прочитаны workflow, sellability, мьют во время
  эфира и доказательство работы STT; нынешние уточнения записаны в VISION.
- `.claude/TESTING.md` прочитана, сохранена. Тесты продуктов при переносе
  правил не запускались, API и старые примеры не объявлены актуальными.
- `.claude/skills/prepare-to-rec` и `meeting-digest` сохранены. Просмотрены
  заголовки и начальные процедуры, переноса/discovery/E2E ещё нет.
  Замечены исторические команды остановки процессов; их нельзя применять
  без проверки владения и текущего контракта. Не копировать skills вслепую.
- `.claude/settings.json`: просмотрены только структура и события hooks,
  без вывода команд/значений. Есть PreToolUse, UserPromptSubmit и Stop.
  Семантика и реальное исполнение в текущей среде — NOT TESTED.
- `.agents/` и `.codex/` в workspace доступны только для чтения. Общие
  hooks/MCP/runtime принадлежат agentops. Изменения там не выполнялись.
- Планы, handoff, STORY и остальная память сохранены на месте. Их содержание
  и глубокий граф ссылок требуют отдельного разбора по необходимости.

  этого переноса. По наличию Markdown не ставим PASS всему проекту.
