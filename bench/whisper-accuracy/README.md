# Whisper accuracy — прогон на сохранённом корпусе

Корпус — те самые `.ogg`, что бот реально принял (`/var/lib/voice-bot/raw/`),
и транскрипты, которые тогда получились (`audit.jsonl`). На 2026-08-01 это
**24 клипа / 322 секунды**.

## Как гонять

```bash
./run.py transcribe                 # прогнать через turbo (ubuntu-home)
./run.py groundtruth                # заготовка для разметки
./run.py report                     # WER, когда truth заполнен
```

Несколько моделей за один проход:

```bash
./run.py transcribe --endpoint turbo=http://192.168.88.13:8000 \
                    --endpoint other=http://host:port
```

Результат — `results-YYYY-MM-DD.jsonl`, одна строка на клип, внутри ответы
всех эндпоинтов.

## Разметка

`./run.py groundtruth` создаёт `ground-truth.jsonl` — по строке на клип:

```json
{"msg_id": 262, "duration_s": 3, "audio": "https://.../msg262.ogg",
 "draft": "Веронись к диспетчеру.", "truth": ""}
```

Слушаешь по ссылке `audio`, правишь `draft` и кладёшь результат в `truth`.
Пустой `truth` = клип не размечен, в WER не попадёт.

Аудио выложено на `https://cashflow-game.ru/voice-out/accuracy/` (Caddy отдаёт
`/srv/voice-out/` статикой). Обновить после новых сообщений:

```bash
cp /var/lib/voice-bot/raw/*.ogg /srv/voice-out/accuracy/
```

## Что уже видно без разметки

Прогон 2026-08-01 через `faster-whisper-large-v3-turbo` (CUDA fp16):

- **msg 172 и 235** в `audit.jsonl` лежат с пустым транскриптом, а сейчас
  распознались нормально. Значит те два провала — инфраструктурные (STT был
  недоступен), а не «неразборчивое аудио». Эвристика «пустой транскрипт при
  duration >2s» из `docs/voice-patterns.md` ловит именно недоступность STT,
  и толковать её как проблему качества нельзя.
- **msg 262** → «Веронись к диспетчеру», **msg 246** → «Вертись обратно к
  ассистенту». Воспроизводятся дословно, значит это устойчивые ошибки модели
  на коротких командах, а не случайный сбой. Обе — императивы «вернись»,
  ровно тот класс фраз, которым переключают фокус.
- Скорость: 250–400 мс на клип до 15с, 2.5с на клип 122с.

## Ограничения

- **Корпус тестовый.** Почти все фразы — «тестовое сообщение», «проверка
  связи». Реальных рабочих запросов с техтерминами и RU+EN mix в нём нет,
  поэтому WER по нему занижен относительно боевого употребления.
- **Сравнение с mac-агентом не автоматизировано.** VK-путь ходит в
  `faster-whisper-large-v3-turbo` на ubuntu-home, mac-агент — в
  `mlx-community/whisper-large-v3-mlx` локально. HTTP-эндпоинта на маке нет,
  так что второй моделью корпус пока не гоняли. Это интересное сравнение:
  turbo когда-то отвергли как «хуже на edge cases», но VK-бот работает
  именно через него.
