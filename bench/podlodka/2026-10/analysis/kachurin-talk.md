## Тезисы

1. **Платим за решённую задачу, а не за токен.** Стоимость = контекст × итерации × цена. Дешёвая модель тратит столько же, но дольше [05:00].
2. **Кэш — главное ограничение, и он теряется всё время.** Префикс замораживается (system + tools), всё изменчивое — в хвост, в сообщение пользователя. Любая модификация истории воспроизводима и сохраняется в БД.
3. **Знания — по требованию.** Скиллы (видимые, скрытые, по кнопке), напоминание + tool вместо подмешивания, векторный поиск плагинов и памяти перед ходом.
4. **Сжатие — по порогу и на границе хода пользователя.** Сначала бесплатный microcompact, LLM summary только на 160k, посреди цикла только аварийно на 200k. Момент сжатия = точка пересборки состояния.
5. **Tools — постоянный налог.** Meta-tools вместо сотен схем; у каждого tool два выхода (UI и модель); RTK, mdream, LLM-фильтр, Context7, граф кода, research-субагент, параллельные вызовы.
6. **Обвязку — в gateway.** Биллинг, алиасы, fallback, ключи, MCP toolsets вне кода агента.

## Голосом сверх слайдов

- Gemini через LiteLLM: hit rate ~15%, прямой API → >90%, «код оброс лишними условиями».
- Подписка ChatGPT: запросы не кэшируются вообще, «лимиты сгорают в момент»; нет картинок, поиска, сжатия; whitelist, только localhost.
- Порог implicit-кэша Google на практике ~16k, а не заявленные 2k.
- Даже смена reasoning effort сбрасывает кэш. Cursor теряет кэш на переключении plan ↔ agent.
- Codex подмешивает незакрытые задачи в сообщение.
- Векторный поиск по каталогу плагинов перед каждым ходом, install-tool с авторизацией.
- Онбординг-скилл на 50+ документов, SEO-скилл, скрытый скилл планирования.
- Microcompact: окно 30 сообщений, условие «и» для 50/60k, «свежий чат» для 160k, лёгкий microcompact перед summary, аварийное сжатие без microcompact.
- 17k токенов на один MCP; 5% OpenRouter; тред на 1 600 человек про activeTools.
- Edit 1 000 → 12 токенов; картинки из tools в vision; Chat Completions не возвращает картинки из tools.
- RTK обрезает середину и кладёт полный лог на диск.
- llms.txt предпочитается странице; zip и прочее неподдержанное фильтруется.
- Context7 «копейки»; от 2 до 120 раз — как заявка авторов; codebase-memory (17 tools) заменён на CodeGraph (1 tool, 400 МБ).
- Пример research-субагента: найти точки бизнеса в Google Maps для блоков сайта.
- Агент всегда на OpenAI Responses API; ключи прячутся, потому что окружение агента доступно пользователю.
