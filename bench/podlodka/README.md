# Podlodka AI Crew #2 — расшифровки

Плейлист [«AI-агенты в разработке»](https://www.youtube.com/playlist?list=PL83wdqv6e7tkTeWB8etFmRwTJs0S8cFj2),
11 сессий, ~11.5 часов. Взяты три наиболее близкие к текущей работе.

| № | доклад | длина | знаков |
|---|---|---|---|
| 05 | AI-first разработка: Claude Code как напарник / Фёдор Догов, Plata | 59 мин | 72K |
| 10 | Spec-Driven Development или Метод Ральфа / Влад Дьяченко | 88 мин | 171K |
| 11 | Субагенты: собираем виртуальную команду / Николай Шейко, overwatch.ai | 61 мин | 96K |

Не брали: стендапы, куратор контента на n8n, детекция аномалий, AI в SRE —
другой стек и не те роли. Круглый стол пропущен как формат: много слов,
мало приёмов.

## Как получено

```bash
./run_all.sh          # скачанное аудио → transcripts/*.md
```

Скачивание — свежий `yt-dlp` в `/root/.venvs/ytdlp` (системный 2024 года
YouTube уже блокирует), только звук. Распознавание — `transcribe_file.sh`
через CUDA-эндпоинт на ubuntu-home, чанки по 30 секунд, примерно впятеро
быстрее реального времени.

## Словарь техтерминов

`prompt.txt` — подаётся в whisper как `initial_prompt`. Проверен на живом
фрагменте:

| без словаря | со словарём |
|---|---|
| «точка код, точка скиллс» | `.code, .skills` |
| «ГВТ или 3А» | `GVT или 3A` |

Латиница сохраняется, имена файлов не превращаются в слова.

**Аббревиатуры всё равно ловятся плохо** — `GVT` почти наверняка искажённое
`TDD`. Для отбора идей не помеха, для дословного цитирования — с оглядкой.
