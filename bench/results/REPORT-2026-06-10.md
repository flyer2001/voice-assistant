## Scope

- **32 audio files** (16 clean + 16 GSM 06.10 degraded). 4 sets: clean RU baseline, RU+EN dev команды, observability, versions/numbers.

## HYP-045 GSM feasibility — Whisper holds, Gemma fails

ΔWER (clean → GSM 06.10):

| Модель | clean | GSM | Δ |
|---|---|---|---|
| Whisper large-v3-turbo (Win-CUDA) | 30.1% | 30.7% | **+0.6%** 🟢 |
| Whisper large-v3 (Win-CUDA) | 30.5% | 29.7% | -0.8% 🟢 |
| Whisper large-v3-turbo (Mac-Metal) | 29.3% | 30.4% | +1.1% 🟢 |
| Whisper medium | 34.9% | 40.0% | +5.1% 🟡 |
| Whisper small | 44% | 52-54% | +7-10% 🟡 |
| **Gemma 3n E2B** | **44.5%** | **65.2%** | **+20.7%** 🔴 |
| Apple DictationTranscriber | 49.8% | 51.3% | +1.6% 🟢 |
| Apple SFSpeechRecognizer | 83.9% | 84.4% | +0.5% (base WER fail) |

**Verdict:** Gemma 3n E2B **не годится для voice IVR через GSM**. Whisper turbo/large robust к узкополосе, Gemma валится.

## Gemma 3n E2B анализ — что не так

Sample transcripts показывают, что Gemma **«интерпретирует»** аудио вместо чистой транскрипции:

| Ground truth | Gemma 3n E2B output |
|---|---|
| "api-latency в Grafana" | **"электросети, графика"** / "эпидемиологии графа" |
| "swift build" | **"CI/CD"** (полностью paraphrased!) |
| "Обнови WhisperKit" | "Навії whisperkit доверие 0.8.3" (degraded) |
| "feature auth" | "feature_aus" (partial) / "GPU-версию" (на длинных) |
| "пятый процентиль" | "пятый тридцати" / "тридцать пятый перцентиль" |

Gemma's instruction-tuned audio model **trained для general understanding**, не для verbatim transcription. Она пытается **понять смысл** и часто **подменяет термины** контекстуальными синонимами.

**Гипотеза не подтверждена:** Gemma audio для verbatim STT хуже Whisper. Возможно интересна для **end-to-end voice→intent** (где интерпретация feature, не bug), но это другой use case.

**Также:** RTX 3070 Laptop 8GB VRAM не вместил Gemma 3n E2B полностью — model offloaded в CPU RAM (peak 11.7 GB RAM, 504 MB VRAM). Это причина latency 25 sec/file (vs Whisper turbo 447ms на той же машине).

## Архитектурное решение voice-assistant v0.1 (W3 RESOLVED — confirmed)

```
Primary path (online):
iPhone → POST /v1/voice/audio multipart
       → Win-CUDA Whisper large-v3-turbo (447ms, 30% WER, 77% Term)
       → text → Happy inject → Claude → reply

Fallback path (offline):
iPhone Apple DictationTranscriber (50% WER, 29% Term)
       → fuzzy intent matcher
       → если recognized → execute
       → если нет → "Нужен онлайн"

NOT used:
- Gemma 3n E2B audio — слабее Whisper на all metrics
- Apple SFSpeechRecognizer — legacy 15s limit, 2% Term
- Apple SpeechTranscriber iOS 26 — broken (empty output)
- Whisper small server-side — Whisper turbo strictly лучше
```
