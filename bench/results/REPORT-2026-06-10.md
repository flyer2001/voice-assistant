## Ключевые инсайты

### 1. Server: **Whisper large-v3-turbo на Win-CUDA** — оптимум для voice-assistant

- WER 30% — основная масса ошибок в Set 4 (numbers/versions ~60% WER), на Set 2 dev cmds только 30%.
- Term Accuracy **77%** на англицизмах (GitHub, pull request, staging, api-latency).
- Latency **447ms** на 15s audio = RTF 0.03 (33× realtime).
- GSM impact: +0.6% — voice IVR жив.

### 2. On-device iPhone: **DictationTranscriber** — лучший Apple stack

- WER **50%** (в 1.7× лучше SFSpeechRecognizer), Term Acc 29%.
- На clean RU baseline почти perfect — **1% WER на Set 1**.
- Бесплатно, system-managed (AssetInventory), 0 MB app bundle overhead.
- Latency 1166ms на iPhone 13 mini A15 — приемлемо.
- Sample на dev cmd: "Запущу ветку **Fitch house** в **GitHub** и открой **Pou Request** на **Review**" — `GitHub` perfect, остальные англицизмы пытается но искажает.

**Это значит DictationTranscriber годится если:**
- Voice-assistant имеет post-STT fuzzy matching на known commands (вместо exact match)
- Или server-side LLM (Claude API) разбирает intent из imprecise транскрипта

### 3. ❌ SpeechTranscriber broken (iOS 26)

100% WER, empty text, 0 ошибок в CSV. Возможные причины:
- `AssetInventory.assetInstallationRequest` silent fail (proxy/HF blocked для Apple's асset CDN?)
- `transcriber.results` AsyncSequence exit'нул до emit (timing/async lifetime)
- Iframe `try await SpeechAnalyzer(inputAudioFile:..., finishAfterFile: true)` finished слишком быстро

Нужно `os_log` debugging через iOS Console.app или `log stream` на mac-home. Откладываю — DictationTranscriber работает, что и было главной целью Apple's new stack.

### 4. Win-CUDA dominates Mac-Metal по скорости (та же модель)

- small: Win 500ms vs Mac 857ms (1.7×)
- medium: Win 889ms vs Mac 1715ms (1.9×)
- turbo: Win 447ms vs Mac 1532ms (**3.4×**)
- large-v3: Win 1154ms vs Mac 2653ms (2.3×)

WER практически identical (±2%). **Production: Win-CUDA primary, Mac-Metal fallback.**

### 5. Cross-platform validation passed

Win/Mac WER differ by <2pp на 8 model×codec pairs. Numbers не platform bias.

### 6. Numbers/versions (Set 4) — главный pain point ALL моделей

Все модели на ~60% WER. "Версия ноль точка восемь точка три" → digit/dot путаница.

**Quick win:** post-STT regex normalization для numeric sequences. Каждый модель прокачается на 10-15pp WER на Set 4.

## Архитектурное решение для voice-assistant v0.1

### Primary path: server-side

```
iPhone (audio capture)
  → AVAudioEngine record
  → POST /v1/voice/audio multipart (specs/backend-protocol.md v2)
  → Win-CUDA Whisper large-v3-turbo (447ms)
  → text → Happy inject → Claude → reply
```

**Tradeoffs:**
- ✅ 77% Term Accuracy на dev cmds, 30% WER
- ✅ GSM-resilient (для HYP-045)
- ❌ Требует connectivity к VDS

### Fallback path: on-device offline

```
iPhone DictationTranscriber (iOS 26)
  → text (50% WER) → fuzzy intent matcher
  → если recognized → execute
  → если не recognized → "Сетевой режим нужен"
```

**Tradeoffs:**
- ✅ Offline, 0 connectivity
- ✅ Бесплатно (no model download)
- ⚠️ 50% WER, 29% term acc — нужна fuzzy intent layer
- ⚠️ Не работает на iOS < 26

### Не используем

- **SFSpeechRecognizer** — 84% WER, 2% term acc, лимит 15s. Только если iOS < 26.
- **SpeechTranscriber** — broken в этой версии iOS 26.5. Re-test позже.
- **Whisper small** — на server-side proigrival turbo по quality (44% vs 30%). Reserve если latency budget tight.
